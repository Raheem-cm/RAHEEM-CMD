# RAHEEM-CMD WhatsApp Bot

This is a simple WhatsApp bot with basic commands like `.ping`, `.owner`, and `.menu`.

## How to run

1. Clone this repository
2. Complete `.env` with your `SESSION_ID` and other details
3. Run `npm install`
4. Run `npm start`

## Deploying on Heroku

- Create a new app on Heroku
- Set environment variables (`SESSION_ID`, `OWNER_NUMBER`, `PREFIX`)
- Deploy your repository
- Enable dyno and start the bot
